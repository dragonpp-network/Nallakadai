
This is a single-file working mock of the full scope from your requirements doc, styled in the நல்ல கடை brand (maroon header/nav, olive "Shop by Categories" pill, cream backgrounds, tinted category sections) — a dark "MOCK CONTROL" bar at the top lets you flip between Customer view and Admin view, and force the cycle open/closed or prices on/off, since one HTML file can't literally be two separate apps.

Customer side — mobile-number login → not-registered / store-closed states → single scrolling categorized item list (tinted sections per category, Tamil + English names) → preset quantity buttons + free-entry field with real min/max validation (try entering 500 kg on Tomato) → running cart total with the "tentative amount" notice → delivery mode/address → order confirmation with an order number → locked view once the cycle closes. "Same as last order" is wired to actually drop unavailable items and re-validate quantities.

Admin side — dashboard (live stats + Not Yet Ordered list with call/export), cycle management (set close date-time, open/close/reopen), cycle availability (per-cycle pricing, copy-previous-cycle, sold-out toggle, min/max override), order list with an editable order modal + non-collection flag, farm order aggregation (CSV + print/PDF), per-customer Order Sheets (individual + batch print), customers, master item list, branches, reports (customer value, item movement, lapsed, non-collection, branch comparison), and an audit log — role-switchable between Branch Admin and Super Admin, which actually scopes the data.
Option to add alternate number in customer master, the alternate number can't be allowed to login.
